## 📌 Projetos principais

### 📦 [GestorIQ](https://github.com/mtmaciel1/GestorIQ-1)
API REST de gestão de estoque, desenvolvida em grupo e totalmente containerizada.
Node.js + Express, PostgreSQL, Redis como cache e Nginx como proxy reverso, tudo orquestrado com Docker Compose. Autenticação JWT, documentação Swagger e script que sobe e prepara o ambiente inteiro.

### 🩺 RECORA *(TCC — em planejamento)*
Plataforma para organizar o processo comercial de empresas que vendem planos de saúde: cadastro de leads, funil, histórico de interações, follow-ups e reativação de oportunidades.
Planejado com React + TypeScript no front, Python + FastAPI no back, PostgreSQL, Docker, Terraform e GitHub Actions, rodando na AWS.

### 🏗️ [Portfólio da disciplina de DevOps](https://github.com/mtmaciel1/unifaat-devops-portfolio)
Laboratórios das aulas: ambientes com Docker Compose e infraestrutura na AWS (IAM, VPC e EC2 Multi-AZ) com Terraform.
